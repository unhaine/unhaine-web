Billain .

반복적인 통신료 청구 작업을 데이터 수집, 검증, 발송이 연결된 웹 기반 시스템으로 전환한 프로젝트.

Workflow Design Automation Web Application
Billain / Process
UPLOAD VALIDATE SEND
01 / THE PROBLEM

Manual steps created friction.

여러 곳에서 내려받은 청구 데이터를 취합하고 계정별로 가공·검증한 뒤 PDF와 메일로 전달하는 과정에서 반복적인 수작업이 발생했습니다.

02 / MY ROLE

From workflow to interface.

업무 규칙, 데이터 구조, 사용자 인터페이스와 실제 운영 흐름을 설계하고 웹 프론트엔드 구현을 주도했습니다. 백엔드 개발은 협업으로 진행했습니다.

03 / THE SOLUTION

One connected workflow.

파일 업로드 → 취합 결과 확인 → 검증 → 발송으로 이어지는 일관된 프로세스를 구성했습니다.

04 / OUTCOME

Days to hours.

기존 약 3일 이상 걸리던 업무를 VBA 단계에서 1~2일로 줄였고, 웹 시스템 도입 후 약 3~4시간 수준으로 단축했습니다.

수치는 당시 실제 운영 경험을 바탕으로 한 비교이며, 표준화된 실험 측정치는 아닙니다.
