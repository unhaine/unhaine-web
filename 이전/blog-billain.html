3일 걸리던 업무를 3시간으로 줄이기까지 — Billain

반복 업무를 줄이려던 작은 시도가 웹 서비스 개발로 이어진 이야기입니다.

1. 모든 것은 야근에서 시작됐습니다

영업 업무를 하면서 가장 손이 많이 갔던 일은 매월 반복되는 통신요금 청구 작업이었습니다.

당시 업무 방식은 그야말로 장인정신의 결정체였습니다. 고객사별 폴더를 만들고, 엑셀 파일을 생성하고, 데이터를 복사하고, 금액을 검증하는 모든 과정을 한 땀 한 땀 수행해야 했습니다.

매월 3일 이상 걸리는 데다 야근도 적지 않았습니다.

처음에는 당연한 업무라고 생각했지만, 같은 작업을 반복하다 보니 의문이 생겼습니다.

'이걸 꼭 사람이 해야 할까?'

자동화에 관심을 갖게 된 시작이었습니다.

2. ChatGPT와 VBA의 만남

2023년, ChatGPT를 접하면서 자동화에 본격적으로 도전했습니다.

당시에는 지금처럼 AI가 프로젝트 전체를 다뤄주는 개발 환경이 아니었습니다. 채팅으로 코드를 물어보고, 직접 복사해 실행하고, 오류가 나면 다시 질문하는 방식이었습니다.

변수와 함수부터 하나씩 배우며 VBA를 익혔습니다.

놀랍게도 엑셀은 생각보다 많은 일을 할 수 있었습니다. 데이터 처리뿐 아니라 폴더 생성, 파일 저장, PDF 변환까지 가능했습니다.

이를 활용해 고객사별 청구서를 자동으로 생성하고 지정된 폴더에 PDF로 저장하는 기능을 만들었습니다.

그 결과 업무 시간이 3일에서 1~2일로 줄었습니다.

자동화의 효과를 직접 경험하니, 조금 더 욕심이 생겼습니다.

3. "그거 돈 낭비 아닐까요?"

이후 다른 부서로 이동했고, 청구 업무는 후임자에게 넘어갔습니다. 하지만 여전히 업무 부담이 컸고, 회사에서도 외부 개발을 검토하게 됐습니다.

받아본 견적은 약 8,000만 원이었습니다.

문제는 비용보다 개발 범위였습니다. 실제로 가장 많은 시간이 소요되는 통신사 데이터 취합 과정은 충분히 해결하지 못하면서, 이미 VBA로 자동화한 청구서 생성 기능이 포함되어 있었습니다.

그래서 의견을 냈습니다.

"이 범위라면 투자 대비 효과가 크지 않을 것 같습니다."

돌아온 답변은 간단했습니다.

"그럼 직접 만들어 보는 건 어때?"

그렇게 예상하지 못했던 웹 개발 프로젝트가 시작됐습니다.

4. 생각보다 쉽지는 않았습니다

청구 업무를 직접 수행했고, VBA로 구현한 경험도 있었기에 업무 규칙에는 자신이 있었습니다.

다만 업무를 이해하는 것과 웹 서비스를 개발하는 것은 다른 문제였습니다.

기능을 추가할수록 코드가 복잡해졌고, 프로젝트 구조를 여러 번 다시 설계해야 했습니다. 지금도 GitHub에는 이름만 다른 비슷한 저장소들이 남아 있습니다. 일종의 시행착오 기록입니다.

그 과정에서 요구사항을 명세하는 방법과 소프트웨어 아키텍처를 공부했습니다. 데이터 구조의 중요성을 느껴 SQLD 강의도 수강했습니다.

모르는 것은 주변에 묻고, 자료를 찾아보고, AI의 도움도 적극적으로 활용했습니다. 한때는 개인 AI 구독료만 월 16만 원 가까이 지출하기도 했습니다.

처음에는 업무를 줄이려고 시작했는데, 어느새 퇴근 후에도 개발을 공부하고 있었습니다.

5. 결국, 해냈습니다

그렇게 완성한 웹 서비스가 Billain입니다.

기존에 여러 프로그램과 엑셀 파일을 오가며 처리하던 업무를 하나의 흐름으로 통합했습니다.

데이터 업로드 → 취합 결과 확인 → 검증 → 청구서 생성 및 발송

구분 소요 시간
기존 수작업 약 3일 이상
VBA 자동화 약 1~2일
Billain 도입 약 3~4시간

Billain은 현재 실제 청구 업무에 사용되고 있습니다.

물론 최신 AI 기술이 적용된 서비스도, 기술적으로 대단히 복잡한 시스템도 아닙니다.

하지만 저에게는 의미가 큰 프로젝트입니다. 불편함을 발견하는 것에서 시작해 업무를 분석하고, 시스템을 설계하고, 실제 운영까지 경험할 수 있었기 때문입니다.

무엇보다 이 경험을 통해 문제를 바라보는 관점이 달라졌습니다.

처음에는 '이 작업을 어떻게 편하게 할까?' 를 고민했다면, 이제는 '이 업무를 어떻게 다시 설계할까?' 를 고민하게 됐습니다.

그리고 그 관심은 자연스럽게 AI와 에이전트 시스템으로 이어지고 있습니다.
